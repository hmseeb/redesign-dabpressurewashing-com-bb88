# DAB Pressure Washing — Website

A complete redesign of the DAB Pressure Washing site. Locally owned, pressure-washing-only
specialists serving Champaign County, IL.

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies, no external APIs.

```
index.html    # entry point (single-page site)
styles.css    # design system + all section styles + responsive rules
script.js     # nav, scroll reveal, stat counters, accordion, quote form
favicon.svg   # favicon placeholder
```

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
```

## Features

- Sticky header with mobile menu and scroll-spy nav highlighting
- Hero with real business photography, animated stat counters and a featured Google review
- Six service cards (house washing, driveway & concrete, deck & fence, commercial, concrete, windows)
- Four-step process section, about band, 12-town service-area grid
- Testimonials, FAQ accordion, and a quote form that composes a prefilled email
- LocalBusiness JSON-LD, Open Graph / Twitter meta, semantic HTML, reduced-motion support
- Fully responsive with a mobile sticky call / quote bar
